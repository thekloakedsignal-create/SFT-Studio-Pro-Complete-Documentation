Part Nine

Settings, Shortcuts & Troubleshooting

This final part collects the reference material you will return to most: every settings page in summary, the complete shortcut list, and the fixes for everything that can go wrong.

9.1  Settings Overview

  • Providers — your API key, connection test, and request timeout.
  • Generation — default aspect ratio, default count, default seed behaviour, and batch limit.
  • Pipelines — the pipeline chained to generation, if any, and the default upscale factor.
  • Library — the output library location, auto-tagging, and trash behaviour.
  • Interface — theme, gallery density, and tooltip verbosity.

Every setting takes effect immediately and is stored with your profile. Nothing in Settings requires a restart.

9.4  Getting More Help

If your problem is not in the table, save your project, note the exact steps that produce the issue, and contact support through the channel supplied with your license. Include the prompt, seed, and settings from the inspector — reproducible reports are resolved fastest.
