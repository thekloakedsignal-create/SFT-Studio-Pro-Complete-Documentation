Part One

Getting Started

Part One takes you from a fresh download to your first generated image. If you follow it start to finish, you will be creating finished work inside SFT Studio Pro in about ten minutes.

1.1  System Requirements

SFT Studio Pro runs comfortably on any modern workstation. Because generation itself happens through your connected provider, the application does not require a dedicated GPU — only a stable connection and enough disk space for your output library.

  • Operating system: Windows 10 or later, macOS 13 or later
  • Memory: 8 GB RAM minimum; 16 GB recommended for large batches
  • Storage: 2 GB for the application, plus space for your output library
  • Network: a persistent internet connection is required for generation

1.2  Installing SFT Studio Pro

  1. Download the installer for your platform from your SFT Studio Pro delivery link.
  2. Run the installer and accept the default installation location.
  3. On first launch, the studio creates its workspace folder, where your projects, presets, and output library will live.

The installer makes no changes outside its own folders, and the application can be moved or removed cleanly at any time.

1.3  Connecting Your Generation Provider

SFT Studio Pro renders through your own provider account. On first launch you will be asked for your API key.

  1. Open Settings → Providers.
  2. Paste your API key into the provider field. The key is stored locally on your machine and is never shared.
  3. Press Test Connection. A green indicator confirms the studio can reach the provider and your key is valid.

Tip. Keep your API key somewhere safe. SFT Studio Pro masks the key after you save it, so you will need the original if you ever reinstall or move machines.

1.4  Your First Image

  1. Click into the prompt field at the top of the generation panel.
  2. Type a simple, descriptive prompt — for example, a ceramic teapot on a linen tablecloth, morning window light.
  3. Leave the aspect ratio at its default, and set the image count to 1.
  4. Click Generate, or press Ctrl+G (⌘+G on macOS).

A few seconds later your image appears in the gallery, selected and ready. From here you can upscale it, grade it, or export it — all of which are covered in the parts ahead.

1.5  If Something Is Not Working

Almost every first-run problem is one of three things: an invalid API key, a blocked network request, or an output folder the application is not allowed to write to. Each has a one-line fix in Part Nine, in the troubleshooting table.
